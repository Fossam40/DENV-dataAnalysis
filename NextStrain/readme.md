You may find here some analysis of the metadata related to dengue virus samples, available at https://data.nextstrain.org/files/workflows/dengue/metadata_all.tsv.zst . The plots were made the 23rd of May, 2025. Additionally, the python notebook contains a small fonction that takes a list of sequences and the metadata associated to it, and filters the sequences from a non-human host. The metadata will not be kept up to date in this repository: if you're interested in it, you should download them directly from NextStrain.
